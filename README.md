# Lab2Web
 Repositori ini memuat seluruh materi latihan dan proyek mini Praktikum 2: HTML Lanjutan untuk mata kuliah Pemrograman Web. Proyek ini disusun secara terstruktur untuk mendemonstrasikan penerapan elemen-elemen HTML5 tingkat lanjut seperti Form Registrasi, Tabel Nilai, Elemen Semantic, dan Integrasi Media Interaktif
